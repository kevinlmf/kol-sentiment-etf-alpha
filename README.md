# KOL-Sentiment-Signal-Alpha

用 KOL 舆情预测行业 ETF 走势，并做信号回测。

## Pipeline

`data_mining` → `data_cleaning` → `nlp` → `signal_testing` → `backtesting`

## Quick start

```bash
pip install -r requirements.txt
bash run_pipeline.sh
```
